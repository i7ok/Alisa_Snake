# Змейка во тьме — история разработки через диалог с AI

Этот проект сделан целиком в разговоре с виртуальным ассистентом: от первой идеи до готовой игры и документации. Ниже — документация взаимодействия: какие запросы давал автор, что делалось на каждом шаге.

## Кто я

Я — **Алиса AI**, виртуальный помощник Яндекса. Работаю на технологиях генеративного искусственного интеллекта: умею вести диалог, писать и отлаживать код, документировать работу — что мы с автором этого проекта и сделали за один разговор.

## Как шла работа

Хронология диалога — каждый запрос автора и что за ним последовало:

| № | Запрос автора | Результат шага |
|---|---------------|----------------|
| 1 | Приветствие и просьба сгенерировать браузерную змейку для GitHub Pages | Полная базовая версия игры в одном файле `index.html`: canvas-рендер, управление стрелками и WASD, пауза, ускорение с ростом счёта, рекорд в `localStorage`, свайпы для мобильных. Плюс пошаговая инструкция по публикации на GitHub Pages |
| 2 | Превратить игру в хоррор: красная змейка, зелёная еда, видимость только в радиусе вокруг головы, всё остальное в тумане; еда вне радиуса не видна | Хоррор-переработка: слой тумана с мягким пятном света вокруг головы, зелёная точка со свечением проявляется только при входе в радиус, тёмная палитра, красная голова со зрачком, экран проигрыша «Ты погас во тьме» |
| 3 | Сообщение «уровень не запускается» | Диагностика: найдена причина — переменная дрожания света использовалась в первой отрисовке до своего объявления, из-за чего скрипт падал целиком и не вешал обработчики ввода. Предложено исправление в одну строку |
| 4 | Просьба прислать весь исправленный код | Полный файл с двумя страховками: инициализация переменной при объявлении и запасное значение в расчёте радиуса. Напоминание, как обновить файл в репозитории |
| 5 | Светящаяся область слишком тёмная; нужен чёткий радиус видимости | Подсветка видимой зоны тёплым светом, чёткая граница тумана с узким переходом, тонкое красноватое кольцо по краю света. Подсказано, какие константы крутить под свой вкус |
| 6 | Детализация визуала: жёлтая сфера под змейкой и чуть меньше радиусом; внутри радиуса светлее; пол в шахматном порядке из тёмно-серых и светло-серых клеток; вокруг радиуса — чёрный; граница света как ступенчатые отметины по клеткам, а не плавный круг | Переработка рендера: жёлтое свечение перенесено под змейку, шахматный пол, ступенчатое затемнение по клеткам вместо градиента — граница света стала «лестницей», сдвигающейся по клеткам |
| 7 | Добавить розовую точку — выглядит как еда, но при съедании мгновенный проигрыш | Ловушка с пульсирующим свечением, невидимая в тумане, отдельный экран проигрыша «Фиолетовая точка забрала тебя», запрет спавна на змейке и на еде |
| 8 | Пусть ловушки обновляют место с каждым очком и добавляется новая — счёт означает количество ловушек | Ловушки переведены в массив: на старте ноль, после каждой еды все перепрятываются и добавляется одна новая, счётчик ловушек выведен в интерфейс. Отмечен естественный потолок сложности и предложена опция «честного» спавна |
| 9 | Просьба создать README диалога без кусков кода | Сначала создан игровой README проекта; после уточнения — этот документ |
| 10 | Вопрос о полноценном скачиваемом файле | Этот файл создан программно и приложен к ответу как готовый `README.md` |

## Что получилось в итоге

- Игра в одном файле без зависимостей: хоррор-змейка в темноте с фонарём у головы.
- Прогрессивная сложность: ускорение темпа плюс растущее число смертельных ловушек.
- Готовая документация: этот файл описывает и проект, и сам процесс его создания.

## Что примечательно в этом диалоге

- Проект сделан итеративно: восемь содержательных правок, каждая строилась на предыдущей версии.
- Единственный баг за всю разработку найден по короткому описанию симптома («не запускается») без логов — по коду предыдущего шага.
- Все решения о визуале и балансе принимал автор; ассистент предлагал варианты и предупреждал о последствиях для геймплея.

## Дальнейшие шаги

В диалоге остались нереализованные идеи, которые можно продолжить в любой момент: уменьшающийся с ростом счёта радиус света, звук сердцебиения, порталы через края поля, запрет спавна ловушек рядом с головой.
